# Publication Google Play

Matériel de la fiche Play Console de la V1 (T123, T124).

| Fichier | Rôle |
| --- | --- |
| fiche-play.md | textes à coller (descriptions, notes de version) et réponses aux questionnaires (accès, public, classification, sécurité des données) |
| politique-confidentialite.html | page à publier sur apexus.fr, son URL va dans la Play Console |
| icone-512.png | icône du store, 512 × 512 |
| banniere-1024x500.png | image de présentation, 1024 × 500 |
| captures/ | captures téléphone 1080 × 1920, refaites par `flutter test --update-goldens tool/store/captures_test.dart` depuis app/ |

L'AAB et le zip des symboles sont dans la release GitHub v1.0.0.
