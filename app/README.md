# app/

Le projet Flutter est créé ici au lot 0 :

```bash
flutter create --org fr.apexus --project-name iacaveavin --platforms android,ios .
```

Ce qui donne l'identifiant Android `fr.apexus.iacaveavin` (docs/09-distribution-publication.md), définitif dès la première installation.
